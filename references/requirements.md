# 要件と対応範囲

## 目的

AIエージェントとの対話で希望を確認し、素材分析から編集・字幕・検収までを再現可能な計画とスクリプトで進める。特定の配信、出演者、社内環境に依存しない一般公開用リポジトリとする。

公開先は `mq-org/ai-video-edit`。既存の制作リポジトリからは再利用可能な処理と知見を抽出し、実素材、文字起こし、個人情報、過去の履歴を持ち込まない。

## 必須機能

1. **ヒアリング**：用途、入力、成果物、長さ、画面比率、字幕、カット方針、保存先を確認する。既知の条件は聞き直さず、「お任せ」の範囲は提案値で進める。
2. **1素材→1本**：30分程度の収録を含む長尺。不要な間・言い直しを整理し、シンプル字幕付きで書き出せる。ショート用の尺制限を適用しない。
3. **1素材→複数ショート**：見どころの選定、縦型化、Type-Tテロップ、カットの継ぎ目の検査。
4. **要望への適応**：採用区間と順序、出力比率・サイズ、字幕の有無と表示設定、音声チャンネル、音量の調整。
5. **確認可能な計画**：編集区間・字幕・設定を保存し、短いプレビューから修正できる。削除理由は案件メモへ記録する。
6. **公開用の分離**：制作データをGit管理外に置き、一般的なコード・文書・架空の例だけを公開する。

## 実装の役割分担

- AIまたは人：文脈の理解、言い直しの判定、残す間、ショート選定、字幕の訂正、検収画像の目視。
- `transcribe.py`：ローカルまたは選択されたAPIでの文字起こし。
- `plan_edit.py`：音声の無音と文字起こしを利用した1本仕上げの下書き作成。
- `edit_video.py`：JSON計画の確認、区間の結合、シンプル字幕とSRT、音声調整、書き出し。
- `typet_shorts.py` / `seams.py`：Python specに基づくType-Tショート、カット点の調整、継ぎ目監査。

JSON計画は素材時刻を基準とし、採用区間の順序に従って出力時間へ変換する。Python specは実行可能なコードであり、信頼できるものだけを扱う。

## 現時点の対象外・限界

- GUIのタイムラインエディタやブラウザアプリは提供しない。
- BGM・効果音の追加、複数素材の統合、複雑な合成、自動の話者追尾は標準機能に含めない。
- 語の正誤や発言の意味をスクリプト単独で確定しない。無音検出の精度は収録条件に依存する。
- 日本語の発話を中心に設計しており、多言語の文字起こし・字幕組版は検証範囲外。
- ローカル文字起こしはApple Silicon向け。その他の環境ではAPIまたは既存の文字起こしを使用する。主な実動確認はmacOSで行う。LinuxのCIはユニットテストと合成素材の書き出しが対象で、実素材を含む全機能の検証ではない。Windowsは未検証。
- 元音声の強い反響・雑音・音割れを自動で修復する機能はない。
- SNSへの投稿・外部共有は標準の制作フローに含めない。

これらを利用者から要望された場合は、既存機能で可能な代替と追加実装を区別する。対象外だからといって、ヒアリング済みの目的を無断で変更しない。

## 公開版の完成条件

100%の範囲は、汎用の1本仕上げとType-Tショートが実行でき、ヒアリング・導入・検収の文書が整い、個人データとライセンスを確認した内容が公開リポジトリへ保存されている状態とする。

- 自動テスト：区間の採用・並べ替え・字幕時刻変換、無音候補の扱い、危険な入力や上書きの拒否。
- 実動確認：合成した検証素材で1本仕上げとType-Tを実際に書き出す。実測の尺・解像度・音声・字幕を確認する。
- 長尺確認：30分程度の入力または同等の区間数で、処理量と時間制限・結合方法を確認する。
- 文書確認：READMEのコマンド、計画例、初回ヒアリング、未実装機能の説明を実装と照合する。
- 公開前確認：制作データ・認証情報・私用パス・実在案件の情報を含まない。依存する素材のライセンス文書を含む。
- 公開確認：GitHubの公開先、可視性、公開ファイルを確認する。

## 検証記録・開発状況

2026-10-30、一般公開版の作成・汎用化は**約100%**。上記完成条件に対し、実装・文書・ローカル検証・公開対象の点検・GitHub公開・CI確認を完了。今回の範囲の残タスクはない。

公開先: https://github.com/mq-org/ai-video-edit （Public / MIT / main）。GitHub上でも制作データを含まない構成を確認した。

実施済みの検証:

- macOS / Apple Silicon / Python 3.13 / FFmpeg 7.1.1で、基本依存とローカル文字起こし用依存を新しい仮想環境へ導入。
- 自動テスト19件成功。区間の並べ替え・反復、字幕時刻、無音の保護、Whisperの0秒語・重複時刻、上書き拒否、特殊文字入りパス、字幕の別納品、実レンダーを含む。
- 30分の合成素材から180か所の無音を短縮。181区間・字幕180枚、完成762秒。計画22,859フレームと出力一致、映像と音声の尺差33ms、48kHzステレオを確認。低解像度320×180での処理量検証であり、4K実素材の速度評価ではない。
- 22秒の日本語合成音声をローカルWhisperで文字起こしし、2か所の間を短縮。1280×720、字幕7枚、19.4秒の動画を生成。日本語字幕の実フレームを確認。
- Type-Tの縦型1080×1920動画を38秒で書き出し、テロップ検収シートを目視。別の34.2秒・9区間のテスト音素材では8継ぎ目すべて監査OK（音声結合を検証するためカット点は固定）。
- GitHub Actions（Linux / Python 3.11）で全19テストと必須環境診断が成功。実装コミットの実行記録: https://github.com/mq-org/ai-video-edit/actions/runs/40990209861
- 制作データ、認証情報、私用パス、実在の制作案件を公開対象から除外。履歴は公開用に新規作成。コードはMIT、同梱フォントはOFL全文付き。

合成音声・テスト音での検証は、実際の収録における誤認識率や編集判断の品質を保証するものではない。API送信、外部動画サイトからの取得、Windowsは今回の実動検証対象外。利用時には素材ごとの検収を行う。
