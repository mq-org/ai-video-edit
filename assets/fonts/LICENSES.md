# 同梱フォント

以下の未改変フォントは、それぞれSIL Open Font License 1.1で配布します。
コードのMITライセンスとは別です。各OFLファイルに著作権表示とライセンス全文を同梱しています。

- `MPLUSRounded1c-Black.ttf`: Rounded M+ 1c Black。本文。`OFL-roundedmplus1c.txt`。
  配布元: https://github.com/google/fonts/tree/main/ofl/roundedmplus1c
- `MochiyPopOne-Regular.ttf`: Mochiy Pop One。リアクション。`OFL-mochiypopone.txt`。
  配布元: https://github.com/google/fonts/tree/main/ofl/mochiypopone
- `ShipporiMinchoB1-ExtraBold.ttf`: Shippori Mincho B1 ExtraBold。タイトル。`OFL-shipporiminchob1.txt`。
  配布元: https://github.com/google/fonts/tree/main/ofl/shipporiminchob1

macOSの追加フォントや市販フォントは含めていません。
