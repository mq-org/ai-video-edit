01 / WHAT YOU CAN MAKE

まずは、この2つから。

編集の入口はClaude Codeとの会話です。AIが素材を調べ、編集計画を作り、このツールでカット・字幕・書き出しを実行します。

STYLE A · 1素材 → 1本

収録を、見やすい1本に。

講座・解説・インタビューなどの言い直しや長い間を整え、シンプルな字幕を付けます。

例：30分の講座 → 内容を保って自然な長さに
完成尺は素材と編集方針で変わります。

横型 / 縦型 / 正方形
STYLE B · 1素材 → 複数本

見どころを、縦型ショートに。

長い動画から話題を選び、色・縁取り・動きのあるテレビ風のテロップを付けます。

例：対談 → 1本で話が伝わるショートを3本
標準の目安は1本30〜90秒です。

縦型 1080 × 1920 / Type-Tテロップ

細かな希望も、会話で指定できます。
「8〜15分だけ使う」「字幕は別ファイルで」「実演は全部残す」など。BGM追加、複数素材の統合、複雑な合成、話者の自動追尾は標準機能の対象外です。希望があれば、追加作業や代替案を相談してください。

02 / BEFORE YOU START

Claude Codeと、動画を用意。

このガイドは、Claude Codeをインストール済みで、会話できる方に向けたものです。編集に必要な道具の準備は、Claude Codeへ依頼します。

用意するもの

  • 普段使っているClaude Code
    Mac上のファイルを扱える状態で開きます。以下の文章は、そのメッセージ入力欄へ送ります。
  • Apple SiliconのMacとネット接続
    M1・M2・M3などのMacが標準です。分からなければ、最初の依頼でClaude Codeに確認してもらえます。
  • 編集してよい動画と空き容量
    最初は短い動画でも大丈夫です。素材がなくても、サンプルで動作を試せます。

費用と文字起こし

  • 本ツールのライセンス料は不要
    Claude Codeの利用料金は別途必要です。
  • 音声認識はMac内で行う設定
    このガイドでは「ローカル文字起こし」を依頼します。文字起こしAPIの従量料金はかかりません。
  • 使えない環境なら、先に相談
    外部の音声認識サービスを使う場合は、音声の送信と料金が発生します。自動で切り替えず、方法を説明してもらいます。
素材の取り扱いについて

音声認識をMac内で行っても、Claude Codeが分析する文字起こしや画像などは、利用するAIサービスへ送信され得ます。外部に渡せない素材は、所属組織の方針とClaude Codeのデータ利用方針を確認してから扱ってください。

Intel Mac・Linux・Windowsを使っている場合

最初の依頼に「私の環境で使えるか確認してください」と添えます。Intel MacやLinuxでは、既存の文字起こしや外部の音声認識サービスを使う方法があります。Windowsは未検証です。Claude Codeから対応範囲と必要な準備を説明してもらってください。

03 / ASK CLAUDE CODE

最初は、この文章を送るだけ。

普段使っているClaude Codeを開き、下の依頼文をコピーして送ります。ツールの取得、必要な道具の導入、動作確認までまとめて依頼できます。

Claude Codeに送る · 初回の準備
ai-video-editを使って動画を編集したいです。
https://github.com/mq-org/ai-video-edit

このツールを私のMacで使えるように準備してください。
私は非エンジニアなので、コードやコマンドの入力を求めず、必要な処理はあなたが実行してください。

まず私のMacで使えるかを確認し、公式の説明とツールの指示書を読んで、必要なものを導入してください。
保存先はホームフォルダ内の「projects」の中の「ai-video-edit」にしてください。すでにあれば、内容を確認して再利用し、既存のファイルは消さないでください。
以降は、そのai-video-editフォルダを対象に作業してください。
文字起こしはMac内で行いたいです。対応していない場合は方法を相談し、外部送信や追加料金のあるサービスへ勝手に切り替えないでください。

私自身の許可やパスワード入力が必要な場合は、理由と画面上の操作を一つずつ案内してください。
最後に動作を確認し、準備できたことと保存場所を教えてください。
まだ本番の動画編集は始めず、次に作りたい動画を聞いてください。

「コマンドを実行してください」と言われたら

04 / YOUR FIRST VIDEO

素材を渡して、希望を伝える。

準備が終わったら、そのまま同じ会話で依頼します。まずは短いプレビューを見て、字幕とカットのテンポを合わせましょう。

① 動画の場所を伝える

「ダウンロードフォルダにある『講座.mp4』を使いたいです」のように、保存場所とファイル名を伝えます。場所が分からなければ、Claude Codeに探し方を案内してもらえます。

正確な場所をコピーしたいときは、Finderで動画を選び、Option＋Command＋Cを押して会話へ貼り付けます。これはファイルの住所を伝える操作です。元動画はそのまま保管してください。

② 最初の依頼を送る

下の例の「ダウンロードフォルダ」「講座.mp4」は、自分の素材に合わせて変えてください。

Claude Codeに送る · 1本仕上げの例
準備したai-video-editを使い、ツールの編集方針に沿って動画を作ってください。

素材は、ダウンロードフォルダにある「講座.mp4」です。
30分程度の講座を、横型の1本の動画に整えたいです。
説明と実演は省かず、言い直しと不要な長い間をカットしてください。
白文字のシンプルな字幕を付け、完成尺は自然な長さにしてください。
文字起こしはローカルで行います。外部の文字起こしサービスを使う場合は、事前に相談してください。

最初に、不足している希望をまとめてヒアリングしてください。
編集計画を確認した後、15〜30秒のプレビューを見てから全編を作りたいです。
完成品は案件ごとにフォルダを分けて保存し、最後にFinderで開いてください。

③ 質問に答え、プレビューを確認する

  1. ヒアリング用途、視聴者、長さ、字幕などを確認。
  2. 素材を分析音声を文字起こしし、映像の状態を調べる。
  3. 編集計画使う区間、削る理由、字幕を整理。
  4. プレビュー短い試作で字幕とテンポを合わせる。
  5. 本書き出し全編を作成し、完成品の場所を案内。

分からない項目には「おすすめを提案して」「字幕の見た目はお任せ」と答えて大丈夫です。残したい箇所は「手元の実演は倍速にせず全部残す」のように具体的に伝えます。

AIから操作の許可を求められたら
対象の素材や保存先、実行内容が依頼に沿っているか確認します。意味が分からなければ「この操作をすると何が変わりますか」と聞けます。文字起こしや書き出しには、素材の長さとMacの性能に応じて時間がかかります。
まだ素材がないので、動作だけ試したい

次の依頼なら、無地の映像・テスト音・架空の字幕で書き出しを試せます。音声認識のテストではありません。

Claude Codeに送る
準備したai-video-editを使ってください。
まだ自分の素材がないので、付属の仕組みで動作確認用のサンプル動画を作ってください。
架空の字幕を付けた15秒のプレビューを書き出し、保存先を教えてください。
サンプルに付属する字幕データを使い、外部の音声認識サービスへは送らないでください。

06 / REVIEW & FINISH

音を聞いて、仕上がりを確認。

AIが案内したMP4をFinderから開き、QuickTime Playerなどで再生します。プレビューで見た範囲に加え、完成後は全編を確認してください。

CHECK 01

言葉と字幕

人名・専門用語の誤字はないか。字幕が画面からはみ出さず、読み切れる速さか。

CHECK 02

音と継ぎ目

語尾が切れていないか。カット前後の音が自然か。声が小さすぎたり、左右で偏ったりしていないか。

CHECK 03

話の流れ

説明や実演が必要以上に省かれていないか。元の発言と違う意味になっていないか。

直したいところは、具体的に伝える

Claude Codeに送る · 修正の例
いま作ったプレビューを見ました。
・完成動画の0分12秒付近で、話し始めの音が少し切れています。カットを緩めてください。
・字幕を少し小さくし、下端から離してください。
・「エーアイ」は「AI」に直してください。
いまの版は残して、新しいファイル名でプレビューを作ってください。

時刻は「元素材の時刻」か「完成動画の時刻」かを添えると確実です。問題がなければ「この仕上がりで全編を書き出してください」と伝えます。

受け取るもの

確認用の試作
字幕やテンポを確かめる短い動画です。見てから修正を頼めます。
完成動画
再生・共有に使うMP4ファイルです。Claude Codeが保存場所を案内します。
字幕ファイル
必要な場合は、字幕を別ファイルでも受け取れます。「字幕も別に欲しい」と伝えてください。
再編集のデータ
文字起こしや編集内容の記録も保存されます。あとで直す予定があれば、素材と一緒に残しておきます。

最後は保存先を確認。
Finderで場所が分からなければ「完成品のフォルダをFinderで開いて」とAIに頼めます。制作データは公開GitHubへ自動保存されません。必要なものは自分のバックアップ先へコピーしてください。YouTubeなどへの投稿は、完成後に別途行います。

07 / NEXT TIME

次も、日本語で続きを頼む。

準備をしたClaude Codeの会話を開き、新しい素材や修正の希望を伝えます。新しい会話から始める場合は、保存済みのツールを使うように依頼してください。

Claude Codeに送る · 次の動画を作る
以前準備したai-video-editを使って、新しい動画を編集したいです。
ホームフォルダ内の「projects」の中にある「ai-video-edit」を確認し、そのフォルダを対象に作業してください。
既存の素材や完成動画は残してください。
今回の素材と仕上がりについて、最初にヒアリングしてください。

準備のときに別の保存場所を選んだ場合は、その場所を伝えてください。以前の動画を直すときは「前に作った講座動画を修正したい」のように、案件名や完成品の場所を添えます。

ツールを最新版へ更新したい

動画の書き出しが終わってから、次の文章を送ります。

Claude Codeに送る · 更新を頼む
ai-video-editを最新版へ更新してください。
進行中の編集がないことを確認し、素材、完成動画、私の設定や変更を残したまま進めてください。
変更がぶつかる場合は勝手に削除せず、対応を相談してください。
更新後に動作を確認し、結果を教えてください。
08 / ASK FOR HELP

困ったときも、そのまま相談。

専門用語を理解したり、設定ファイルを直したりする必要はありません。今起きていることを、同じClaude Codeの会話で伝えてください。

準備の途中で止まった・エラーが出た

「準備が途中で止まっています。原因を調べて、続きの作業をしてください」と伝えます。別の画面にエラーが出ている場合は、その文章を添えてください。

「すでにフォルダがあります」と言われた

「以前のai-video-editか確認し、使えるならそのまま使ってください。中の素材や設定は消さないでください」と伝えます。別のものなら、保存先を相談します。

文字起こし・書き出しが長くかかっている

「いま何の処理をしていますか。止まっていないか確認してください」と聞けます。初回の文字起こしは、音声認識に必要なデータの取得にも時間がかかります。同じ処理を重複して始めず、状況を確認してもらいます。

素材が見つからないと言われた

「動画はMacのダウンロードフォルダにある『講座.mp4』です」のように、保存場所と名前を伝えます。候補が複数あるときは、どれを使うか確認してもらってください。クラウド上だけにある素材は、Macへの保存方法を案内してもらいます。

許可を求められたが、内容が分からない

「この操作を許可すると何が変わりますか。動画編集に必要な理由を、簡単に説明してください」と聞いてから判断できます。

字幕やカットを直したい・完成品が見つからない

「完成動画の2分10秒の字幕を直して」「この実演は全部残して」「完成品のフォルダをFinderで開いて」のように頼んでください。再書き出しのときは、前の版を残すように伝えると見比べられます。

Claude Codeに送る · 困ったときの依頼文
ai-video-editで、次のところで困っています。
「ここに、今起きていることを書いてください」

原因を確認し、できる作業はあなたが実行して解決してください。
既存の素材や編集データは残してください。
コードやコマンドの入力は求めず、私自身の操作が必要な部分だけ、画面上の手順を一つずつ教えてください。

パスワードや秘密のキーは会話に貼り付けないでください。公開のGitHub Issuesへ相談する場合は、個人情報や非公開の文字起こしを取り除いてください。
