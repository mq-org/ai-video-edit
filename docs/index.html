A practical guide to AI video editing

作りたい動画を、
言葉で伝える。

ai-video-edit は、AIに日本語で相談しながら使う動画編集ツール集です。素材を用意したら、残したい内容や仕上がりを伝えるところから始めましょう。

はじめての導入から完成まで日本語の動画に対応コードの手書きは不要
導入手順へ進む 　↓依頼文の例を見る
INPUT手元の動画素材
→
EDITAIと相談して編集
→
OUTPUT字幕付きの完成動画
01 / WHAT YOU CAN MAKE

まずは、この2つから。

編集の入口はClaude Codeとの会話です。AIが素材を調べ、編集計画を作り、このツールでカット・字幕・書き出しを実行します。

STYLE A · 1素材 → 1本

収録を、見やすい1本に。

講座・解説・インタビューなどの言い直しや長い間を整え、シンプルな字幕を付けます。

例：30分の講座 → 内容を保って自然な長さに
完成尺は素材と編集方針で変わります。

横型 / 縦型 / 正方形
STYLE B · 1素材 → 複数本

見どころを、縦型ショートに。

長い動画から話題を選び、色・縁取り・動きのあるテレビ風のテロップを付けます。

例：対談 → 1本で話が伝わるショートを3本
標準の目安は1本30〜90秒です。

縦型 1080 × 1920 / Type-Tテロップ

細かな希望も、会話で指定できます。
「8〜15分だけ使う」「字幕は別ファイルで」「実演は全部残す」など。BGM追加、複数素材の統合、複雑な合成、話者の自動追尾は標準機能の対象外です。希望があれば、追加作業や代替案を相談してください。

02 / BEFORE YOU START

準備するものを確認。

パソコンと素材

  • Apple SiliconのMac
    M1・M2・M3など、Apple製チップ搭載機。「 → このMacについて」で確認できます。
  • インターネット接続
    ツールの導入、AIとの会話、初回の音声認識モデル取得に使います。
  • 編集してよい動画と空き容量
    まずは短いMP4がおすすめ。元素材・中間ファイル・完成品を置ける余裕を用意します。

この手順はHomebrewがサポートするmacOSを前提にしています。対応OSはHomebrew公式で確認してください。

アカウントと費用

  • Claude Codeを使えるアカウント
    対応するClaudeの契約、またはClaude Console等の利用環境が必要です。最新の対象は公式ガイドを確認してください。
  • ツール本体はMITライセンス
    ai-video-editの利用料と、AIサービスの利用料金は別です。本体のライセンス料はありません。
  • 標準手順はローカル文字起こし
    音声認識をMacで行うため、文字起こしAPIの従量料金はかかりません。Claude Codeの利用料金は別途必要です。

公開リポジトリのダウンロードに、GitHubアカウントは必要ありません。

「ローカル文字起こし」の範囲

音声認識はMac内で動きます。一方、Claude Codeが分析する文字起こしや画像などは、利用するAIサービスへ送信され得ます。外部に渡せない素材は、所属組織の方針とClaude Codeのデータ利用方針を確認してから扱ってください。

Intel Mac・Linux・Windowsを使っている場合

ローカル音声認識のmlx-whisperはApple Silicon向けです。Intel Macは下記セットアップの --with-local を外し、API文字起こし、または既存の文字起こしを利用してください。APIにはOpenAI側の設定と料金が必要で、音声が外部サービスに送信されます。

LinuxはREADMEの手動セットアップを参照してください。Linuxの確認範囲はテストと合成素材の書き出しで、Windowsは未検証です。このガイドのコマンドをそのままWindowsへ貼り付けないでください。

03 / ONE-TIME SETUP

最初の1回だけ、道具を準備。

以下は上から順に進めます。すでに導入済みの項目は、動作を確認して次へ進んでください。保存先はホームフォルダ内の projects/ai-video-edit に統一します。

このページの読み方
濃い色の「ターミナルに貼る」はMacへの操作指示。薄い緑色の「Claude Codeに送る」はAIへの依頼文です。コピーボタンで本文だけをコピーできます。
1

ターミナルを開く

⌘ Command ＋ Space を押して「ターミナル」と入力し、Returnで開きます。ここにコマンドを貼り付け、Returnを押して実行します。

コマンドは1つの枠ずつ実行してください。文字が流れている間は完了を待ちます。パスワード入力では文字も「●」も表示されません。そのままMacのログインパスワードを入力してReturnを押します。

2

Homebrewを用意する

Homebrewは、必要な道具をまとめて導入する仕組みです。まず確認します。

ターミナルに貼る · 導入済みか確認
brew --version

バージョン番号が出れば手順3へ。command not found と出た場合は、公式サイトのインストールコマンドを実行します。

ターミナルに貼る · 未導入の場合だけ
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

最後に表示される「Next steps」の指示も実行してください。ターミナルからHomebrewを使えるようにする設定です。開発ツールのインストール画面が出たら、案内に従って完了を待ちます。

完了の目印：新しいターミナルで brew --version が表示される。
3

Claude CodeとGitを入れる

Claude CodeはAIとの会話用、Gitはこのツールの取得と更新用です。

ターミナルに貼る
brew install git
brew install --cask claude-code
ターミナルに貼る · インストール確認
git --version
claude --version
完了の目印：両方のバージョン番号が表示される。

この手順はClaude Code公式のHomebrew導入方法を使用します。別の方法でClaude Codeを導入済みなら、重ねてインストールする必要はありません。

4

ai-video-editをダウンロードする

次の2行を実行すると、決まった場所にフォルダが作られます。

ターミナルに貼る
mkdir -p "$HOME/projects"
git clone https://github.com/mq-org/ai-video-edit.git "$HOME/projects/ai-video-edit"

$HOME は、あなたのホームフォルダを指します。そのままコピーして使えます。すでに同じフォルダがある場合は削除せず、困ったときを確認してください。

5

動画編集の道具をまとめて入れる

Apple SiliconのMacでは、次の1行で編集とローカル文字起こしの準備をします。初回はダウンロードが多いため、完了まで待ちます。

ターミナルに貼る · Apple Silicon用
bash "$HOME/projects/ai-video-edit/scripts/setup.sh" --with-local

FFmpeg、Python、文字起こし用ライブラリなどが導入されます。字幕用フォントは本体に同梱されています。音声認識モデルは、最初の文字起こし時に取得されます。

ターミナルに貼る · 準備を確認
"$HOME/projects/ai-video-edit/.venv/bin/python" "$HOME/projects/ai-video-edit/scripts/check_env.py"
完了の目印：「編集の必須項目はOK」と表示される。

ローカル文字起こしを使う場合、OpenAI APIの「任意・未導入」は問題ありません。mlx-whisperが使える状態かも確認してください。

6

このフォルダでClaude Codeを起動する

次のコマンドを使うと、編集用のフォルダを作業場所として起動できます。

ターミナルに貼る · 毎回このコマンドで起動
(cd "$HOME/projects/ai-video-edit" && claude)

初回は画面の案内に従ってログインします。ブラウザが開いたら認証を済ませ、ターミナルへ戻ります。フォルダの信頼確認が出たら、場所が projects/ai-video-edit であることを確認します。

完了の目印：Claude Codeで文章を入力できる。

ログインし直すときはClaude Code内で /login、操作案内は /help。詳細は公式クイックスタートを参照してください。

04 / YOUR FIRST VIDEO

素材を渡して、希望を伝える。

ここからはAIとの会話が中心です。編集の設定ファイルはAIが用意します。まずは短いプレビューを見て、字幕とカットのテンポを合わせましょう。

① 動画の場所を伝える

Finderで動画を選び、⌥ Option ＋ ⌘ Command ＋ C でファイルのパスをコピーします。下の依頼文にある「ここに動画のパス」を、コピーした内容に置き換えてください。

パスはファイルの住所です。例：/Users/あなたの名前/Movies/lesson.mp4。名前だけを伝えるより、どの素材を使うか確実に分かります。元動画はそのまま保管してください。

② 最初の依頼を送る

Claude Codeに送る · 1本仕上げの例
このプロジェクトのCLAUDE.mdとreferences/workflow.mdを読んで、動画編集を進めてください。

素材は「ここに動画のパス」です。
30分程度の講座を、横型の1本の動画に整えたいです。
説明と実演は省かず、言い直しと不要な長い間をカットしてください。
白文字のシンプルな字幕を付け、完成尺は自然な長さにしてください。
文字起こしはローカルで行います。APIへの切り替えは事前に相談してください。

最初に、不足している希望をまとめてヒアリングしてください。
編集計画を確認した後、15〜30秒のプレビューを見てから全編を作りたいです。
完成品はoutput/内に案件用フォルダを作って保存し、最後に保存先を教えてください。

③ 質問に答え、プレビューを確認する

  1. ヒアリング用途、視聴者、長さ、字幕などを確認。
  2. 素材を分析音声を文字起こしし、映像の状態を調べる。
  3. 編集計画使う区間、削る理由、字幕を整理。
  4. プレビュー短い試作で字幕とテンポを合わせる。
  5. 本書き出し全編を作成し、完成品の場所を案内。

分からない項目には「おすすめを提案して」「字幕の見た目はお任せ」と答えて大丈夫です。残したい箇所は「手元の実演は倍速にせず全部残す」のように具体的に伝えます。

AIから操作の許可を求められたら
対象の素材や保存先、実行内容が依頼に沿っているか確認します。意味が分からなければ「この操作をすると何が変わりますか」と聞けます。文字起こしや書き出しには、素材の長さとMacの性能に応じて時間がかかります。
まだ素材がないので、動作だけ試したい

次の依頼なら、無地の映像・テスト音・架空の字幕で書き出しを試せます。音声認識のテストではありません。

Claude Codeに送る
CLAUDE.mdとreferences/workflow.mdを読んでください。
scripts/make_demo.pyでデモ素材を作り、1本仕上げの編集計画を作成・確認してください。
架空の字幕を付けた15秒のプレビューを書き出し、保存先を教えてください。
デモには既存の文字起こしがあるので、音声認識やAPI送信は不要です。
05 / WRITE YOUR BRIEF

あなたの動画の、依頼文を作る。

選択すると、下の文章が変わります。コピーしてClaude Codeに送り、会話の出発点にしてください。このフォームは依頼文を作るだけで、動画のアップロードや編集の実行は行いません。入力内容も送信しません。

このフォームはApple Siliconでのローカル文字起こしを指定します。違う環境なら、送る前にその行を変更してください。Type-Tは縦型ショート向けのため、組み合わせは自動で調整します。

Claude Codeに送る · あなたの依頼文
CLAUDE.mdとreferences/workflow.mdを読んで、動画編集を進めてください。
素材は「ここに動画のパス」です。1本に整えたいです。
横型で、白文字のシンプルな字幕を付けてください。
長い間と言い直しを整理し、説明は残してください。
文字起こしはローカルで行い、APIへの切り替えは事前に相談してください。
まず不足する希望をヒアリングし、短いプレビューを見てから全編を作ってください。
完成品はoutput/内に案件用フォルダを作って保存し、保存先を教えてください。
ショートを依頼する例文も見たい
Claude Codeに送る · 見どころを3本に
CLAUDE.mdとreferences/workflow.mdを読んでください。
素材「ここに動画のパス」から、初めて見る人向けの縦型ショートを3本作りたいです。
1本30〜60秒を目安に、結論まで1本で理解できる話題を選んでください。
1080×1920、テレビ風のType-Tテロップで仕上げたいです。
文字起こしはローカルで行います。最初に希望を確認し、候補の話題と切り出す理由を提案してください。
まず代表1本のプレビューを見てから、残りを制作してください。
完成品はoutput/内に保存し、保存先を教えてください。
06 / REVIEW & FINISH

音を聞いて、仕上がりを確認。

AIが案内したMP4をFinderから開き、QuickTime Playerなどで再生します。プレビューで見た範囲に加え、完成後は全編を確認してください。

CHECK 01

言葉と字幕

人名・専門用語の誤字はないか。字幕が画面からはみ出さず、読み切れる速さか。

CHECK 02

音と継ぎ目

語尾が切れていないか。カット前後の音が自然か。声が小さすぎたり、左右で偏ったりしていないか。

CHECK 03

話の流れ

説明や実演が必要以上に省かれていないか。元の発言と違う意味になっていないか。

直したいところは、具体的に伝える

Claude Codeに送る · 修正の例
いま作ったプレビューを見ました。
・完成動画の0分12秒付近で、話し始めの音が少し切れています。カットを緩めてください。
・字幕を少し小さくし、下端から離してください。
・「エーアイ」は「AI」に直してください。
いまの版は残して、新しいファイル名でプレビューを作ってください。

時刻は「元素材の時刻」か「完成動画の時刻」かを添えると確実です。問題がなければ「この仕上がりで全編を書き出してください」と伝えます。

保存されるファイル

MP4
再生・共有に使う完成動画。*.preview.mp4 は確認用の試作です。
SRT / ASS
1本仕上げで字幕を有効にしたときの字幕ファイル。SRTは字幕の別納品、ASSは表示設定を含む字幕データです。
report.json
1本仕上げの検査レポート。通常はAIが内容を確認します。
data/
文字起こし、編集計画、中間データなど。再編集に使います。
output/
このガイドで指定する完成品の保存先。案件名ごとにまとめます。

最後は保存先を確認。
Finderで場所が分からなければ「完成品のフォルダをFinderで開いて」とAIに頼めます。制作データは公開GitHubへ自動保存されません。必要なものは自分のバックアップ先へコピーしてください。YouTubeなどへの投稿は、完成後に別途行います。

07 / NEXT TIME

2回目からは、起動して相談。

インストールを繰り返す必要はありません。ターミナルで次を実行し、新しい素材と希望を伝えます。

ターミナルに貼る · Claude Codeを起動
(cd "$HOME/projects/ai-video-edit" && claude)

以前の会話を続ける場合は、Claude Code内で /resume を入力して会話を選びます。新しい会話で再編集する場合は、案件名や編集計画の場所を伝えてください。

ツールを最新版へ更新したい

進行中の書き出しが終わってから、別のターミナルで実行します。このガイドのHomebrew方式で導入したClaude Codeも更新できます。

ターミナルに貼る · 更新
git -C "$HOME/projects/ai-video-edit" pull --ff-only
brew upgrade claude-code
bash "$HOME/projects/ai-video-edit/scripts/setup.sh" --with-local

ローカルの変更があってGitが止まった場合は、エラーをAIに見せてください。既存フォルダを消したり、変更を強制的に破棄したりする必要はありません。

08 / TROUBLESHOOTING

つまずいたら、ここを確認。

エラーが出ても、最初からやり直す前に原因を確認できます。画面の文章をそのままAIへ伝えると、対処しやすくなります。

brew: command not found と出る

Homebrewのインストール末尾にある「Next steps」を実行したか確認してください。新しいターミナルを開き直して brew --version を試します。まだ使えなければ、公式の導入案内とインストール時の表示を確認します。

git / claude: command not found と出る

手順3がエラーなく完了したか確認し、新しいターミナルでバージョン確認をやり直します。Homebrew自体が使えない場合は、先にその問題を解決してください。Claude Codeのログインと、コマンドのインストールは別の手順です。

「フォルダが既にある」「No such file」と出る

すでに取得済みなら、同じ場所への git clone は不要です。Finderの「移動 → フォルダへ移動」で ~/projects/ai-video-edit を開き、README.mdやscriptsフォルダがあるか確認します。

別の場所へ取得した場合は、コマンド内の保存先をその場所に合わせます。名前が同じでも中身が別のフォルダなら、削除せず、別名で取得する方法を相談してください。

ローカル文字起こしが使えない

Apple SiliconのMacか、setup.sh --with-local が完了したかを確認します。手順5の環境チェック結果をAIに伝えてください。Intel MacやLinuxではAPIまたは既存の文字起こしを選びます。APIへの切り替えには外部送信と料金が伴います。

文字起こし・書き出しが終わらないように見える

初回の文字起こしではモデルのダウンロードが入ります。長い素材や高解像度の動画は処理にも時間がかかります。「現在の処理とログを確認して、進行しているか教えて」とAIに頼んでください。処理中に同じ書き出しを重複して開始しないようにします。

素材が見つからない・読み取れない

Finderで動画を選び直し、Option＋Command＋Cでパスをコピーします。クラウド上にしかないファイルは、まずMacへダウンロードしてください。読み取り権限の確認が出た場合は対象フォルダを確認します。

「未確認の計画」「出力が既に存在する」で止まる

AIに「カット・字幕・出力設定を確認したうえで計画を確定して」と伝えます。確認済みの印だけを変更する必要はありません。出力済みなら「前の版を残して、v2という別名で書き出して」と依頼できます。

字幕の誤字やカットの違和感を直したい

正しい表記と、どの動画の何分何秒かを伝えます。「この間は実演を見せる時間なので残す」「『株式会社サンプル』が正式名称」のような情報が有効です。音声認識も編集判断も、素材ごとの確認が必要です。

Claude Codeに送る · エラーを相談
ai-video-editの「ここに手順名」で止まりました。
環境は「Macのチップ名 / macOSのバージョン」です。
実行した内容とエラーを下に貼ります。
原因を調べ、既存の素材や編集データを残したまま、次に行う操作を教えてください。

【実行した内容】
ここに貼り付け

【エラー】
ここに貼り付け

APIキーやパスワードは貼り付けないでください。公開のGitHub Issuesへ相談する場合は、個人情報や非公開の文字起こしを取り除いてください。
